# Word list sources

Both lists below are public domain. Neither author requires attribution as a
condition of use, but both ask for it, so it is kept here and in
`docs/design.md` §5.2 rather than dropped.

## enable1.txt

ENABLE (Enhanced North American Benchmark LExicon), first edition. Compiled
by Alan Beale and Mendel Cooper. Formally released to the public domain — no
fee, no registration, no conditions. Source:
<https://github.com/dolph/dictionary> (a long-standing mirror; ENABLE's
original site is no longer online).

## 3of6game.txt

From the 12dicts word list package, release 6.0.2, compiled by Alan Beale.
Most of 12dicts is explicitly released to the public domain by its compiler;
`3of6game` (in the `International` directory of the package) is one of the
files so released — it does not depend on AGID, unlike a handful of other
lists in the package (`2of12inf`, the `2+2+3*` lemmatized lists) which carry
that dependency's separate terms and were not used here. Source:
<https://wordlist.aspell.net/12dicts/>.
